# Bernoulli OOD 평가 분석 — Run 16·21·22

분석일: 2026-09-14. 기존 9종 OOD와 공통 Base 환경의 평가 9,000행을 분석했습니다.

## 판단

**현재 논문의 기준 모델은 16번으로 유지하고, 21번은 고부하에서의 장점을 보여주는 보완 결과, 22번은 학습 범위 효과를 살펴보는 비교 모델로 두는 것이 적절합니다.** 세 모델 모두 이번에 평가한 기존 6종 스케줄러보다 모든 환경에서 완료 패킷 goodput과 deadline miss가 좋았습니다. 다만 한 모델이 모든 지표에서 최상인 것은 아닙니다.

16번은 평균 goodput이 10개 환경 중 7개에서 가장 높습니다. 21번은 P055·STORM2·K48에서 평균 goodput이 가장 높고, K60까지 포함한 고부하 4개 환경에서 reward와 deadline miss가 두 다른 모델보다 좋습니다. **NARROW 22번이 OOD에서 무너진다는 가설은 이번 결과로 지지되지 않습니다.**

## 무엇을 비교했는가

| 모델 | 학습 이력 | 평가 checkpoint |
|---|---|---:|
| 16 | Base 1,000회 후 낮은 LR로 재시작하여 총 2,000회 | best@1989 |
| 21 | Base 처음부터 2,000회, LR을 전체 기간에 걸쳐 감소 | best@649 |
| 22 | 평균 부하·인원·속도를 맞춘 NARROW, 처음부터 2,000회 | best@1469 |

모든 정책을 추가 학습 없이 동결했습니다. 모든 평가 환경은 21번의 Base Bernoulli 설정에서 출발합니다. 22번도 같은 환경에서 평가했으므로 이 표의 ID는 “공통 Base ID”이며 NARROW 자체 학습 환경을 뜻하지 않습니다. 모든 학습 seed는 2024입니다. 학습 중 checkpoint 선택에 사용한 3개 에피소드와 이번의 새로운 100개 에피소드는 구성이 다르므로, 학습 로그보다 평균 goodput이 낮아진 것을 모델 성능 저하로 해석하면 안 됩니다.

각 환경에 동일한 평가 에피소드 140000–140099를 사용했습니다. 별도 pilot 139000–139007에서 SUS threshold를 선택했습니다. 기존 비교군은 SUS/SU × CQI/PF/Random 6종이며, 세 모델과 모든 비교군의 총 9개 스케줄러를 10개 환경에서 각각 100회 평가했습니다.

평가 한 회는 1,000슬롯(0.5초)입니다. 에피소드가 통계 단위이며, 슬롯이나 패킷을 독립 반복으로 취급하지 않았습니다. 모델·정규화 buffer·Torch RNG·평가 입력 해시는 평가 전후 동일했습니다.

## 완료 패킷 goodput

단위는 Mbps입니다. 굵은 값은 세 PPO 중 가장 높은 표본 평균입니다. 표의 baseline은 **각 환경에서 6종 중 mean goodput이 가장 높았던 방법**입니다. 이는 결과 요약 기준이며 환경을 보고 자동으로 교체하는 하나의 배포 정책을 뜻하지 않습니다.

| 환경 | 비교군 | 비교군 goodput | 16번 | 21번 | 22번 |
|---|---|---:|---:|---:|---:|
| ID | SUS+CQI | 75.032 | **77.576** | 77.407 | 77.412 |
| P055 | SUS+CQI | 112.273 | 115.336 | **115.759** | 115.516 |
| P010 | SU+CQI | 29.646 | **29.924** | 29.813 | 29.855 |
| V60max | SUS+CQI | 74.742 | **77.187** | 77.015 | 77.032 |
| CSI02 | SUS+CQI | 70.539 | **73.021** | 72.650 | 72.818 |
| D26strict | SUS+CQI | 71.868 | **74.779** | 74.505 | 74.722 |
| STORM2 | SUS+CQI | 102.385 | 105.645 | **105.804** | 105.707 |
| K8 | SUS+CQI | 31.228 | **31.624** | 31.577 | 31.599 |
| K48 | SUS+CQI | 126.218 | 127.812 | **128.099** | 127.960 |
| K60 | SUS+CQI | 144.286 | **145.378** | 145.053 | 145.176 |

**P010에서는 SU+CQI가 가장 강합니다.** SUS+CQI만 기준으로 잡으면 저부하에서의 이득을 과장하게 됩니다. 가장 강한 기존 비교군 대비 모든 모델/환경의 goodput 향상은 +0.531~4.050%, deadline miss 감소는 0.523~2.860%p입니다. 16번만 보면 9종 OOD의 goodput 향상 범위는 +0.757~4.050%입니다.

![비교군 대비 이득](baseline-gains.png)

세 모델 × 6개 비교군 × 10개 환경에서 goodput·reward·deadline miss의 paired 95% 구간이 모두 PPO에 유리한 방향으로 0을 제외합니다. 추가 사후 민감도 분석으로 540개 비교 전체에 Holm 보정을 적용해도 모두 유의했습니다(최대 보정 p=0.001796). 이는 사전 등록된 주 검정은 아니며, 학습 seed에 대한 재현성을 보장하지 않습니다.

## 16번과 21번의 차이

16번은 기본 환경·저부하·CSI 갱신 감소·짧은 deadline에서 유리하고, 21번은 높은 부하에서 packet deadline을 더 잘 지킵니다. 모델 간 goodput 차이는 대체로 0.1~0.4 Mbps이므로 비교군 대비 이득보다 작습니다. 아래 구간은 같은 에피소드끼리 차이를 낸 pointwise 95% Student-t 구간입니다. Deadline miss 차이는 음수일수록 왼쪽 모델에 유리합니다.

| 환경 | 왼쪽−오른쪽 모델 | Goodput 차이 Mbps [95% CI] | Deadline miss 차이 %p [95% CI] |
|---|---|---:|---:|
| ID | 16−21 | +0.169 [+0.050, +0.288] | -0.143 [-0.238, -0.049] |
| CSI02 | 16−21 | +0.371 [+0.269, +0.472] | -0.222 [-0.304, -0.141] |
| D26strict | 16−21 | +0.274 [+0.156, +0.391] | -0.230 [-0.330, -0.130] |
| P055 | 21−16 | +0.422 [+0.284, +0.561] | -0.265 [-0.328, -0.203] |
| STORM2 | 21−16 | +0.159 [+0.015, +0.302] | -0.121 [-0.191, -0.051] |
| K48 | 21−16 | +0.287 [+0.137, +0.438] | -0.228 [-0.291, -0.164] |
| K60 | 21−16 | -0.325 [-0.602, -0.048] | -0.137 [-0.205, -0.069] |

**K60은 성능 교환관계가 분명합니다.** 16번은 goodput 145.378Mbps로 21번 145.053Mbps보다 높지만, deadline miss는 21번이 49.202%로 16번 49.339%보다 낮습니다. 21번은 총 919,268개, 16번은 917,875개 패킷을 완료했습니다. 완료 패킷의 평균 크기는 21번 7,889.6bits, 16번 7,919.3bits입니다. 즉 21번은 패킷 수, 16번은 완료 비트 수에서 유리합니다.

모델 간 90개 비교(3쌍 × 10환경 × 3지표)에 대한 Holm 사후 분석에서는 42개가 유의했습니다. 21번의 고부하 4개 환경에서 reward·deadline miss 우위는 16번과 22번 모두에 대해 유지됩니다. 16↔21 goodput 차이는 P010·CSI02·D26에서 16번, P055·K48에서 21번의 우위가 보정 후 유지됩니다. STORM2·K60의 goodput 차이는 보정 후 확실하지 않습니다.

## NARROW와 넓은 학습 범위

**22번은 기존 비교군을 모든 환경에서 이기며 16·21번과 상당히 가깝습니다.** 21번과 22번의 ID goodput 차이는 0.005Mbps 미만, V60max는 0.018Mbps 미만입니다. 22번은 CSI02에서 21번보다 +0.168Mbps, D26strict에서 +0.217Mbps 높고, 두 차이는 모델 간 Holm 분석에서도 유지됩니다.

따라서 “넓은 학습 범위가 모든 OOD에서 필수적이다”라는 주장은 맞지 않습니다. 더 정확한 결론은 **넓게 학습한 21번이 고부하의 deadline 관리에서 장점이 있지만, NARROW도 상당히 잘 일반화한다**입니다. 학습 범위의 효과는 학습 횟수와 LR 계획이 같은 21↔22 비교를 중심으로 판단해야 합니다. 16번은 이어 학습한 이력이 다르므로 16↔22 차이를 학습 범위만의 효과로 설명할 수 없습니다.

## 무선통신 관점의 의미

**관측된 개선의 중심은 실제 패킷 완료 성능입니다.** CSI02에서 16번과 SUS+CQI의 ACK 비트 처리량은 거의 같지만, deadline 안에 완결된 패킷의 goodput은 더 높습니다. K60에서도 16번은 더 낮은 ACK 비트 처리량으로 더 높은 완료 패킷 goodput을 보입니다.

| 환경 / 방법 | ACK 처리량 Mbps | 완료 goodput Mbps | Deadline miss % | 첫 전송 ACK % |
|---|---:|---:|---:|---:|
| CSI02 / Run 16 | 75.766 | 73.021 | 36.227 | 85.270 |
| CSI02 / sus_cqi | 75.720 | 70.539 | 38.390 | 87.132 |
| K60 / Run 16 | 149.664 | 145.378 | 49.339 | 93.817 |
| K60 / sus_cqi | 152.063 | 144.286 | 49.962 | 95.001 |

ACK 처리량과 goodput의 차이에는 deadline을 넘긴 패킷에 전달한 일부 비트와 평가 종료 시 미완료 패킷의 일부 비트가 포함될 수 있습니다. 이 차이를 모두 낭비나 재전송이라고 부를 수 없습니다. 첫 전송 ACK 비율은 모든 에피소드에서 첫 시도에 ACK된 전송 단위 수의 합계를 새 전송 단위 수의 합계로 나눈 값입니다.

21번의 평균 MU depth는 모든 환경에서 16번보다 높습니다. P010에서 16/21은 2.065/2.302, P055에서는 3.381/3.463입니다. 이 차이는 관측된 정책 동작의 차이를 보여주지만, MU depth가 성능 차이의 원인이라는 인과 증거는 아닙니다. 여기서 MU depth는 UE별 동시 스케줄링 깊이의 평균이며 RBG 점유율이나 자원 이용률 자체가 아닙니다.

CSI 갱신이 드문 CSI02는 속도 범위를 늘린 V60max보다 이번 실험에서 영향이 컸습니다. 16번의 ID 대비 goodput 변화는 V60max −0.50%, CSI02 −5.87%이며, 첫 전송 ACK는 ID 93.80%에서 CSI02 85.27%로 낮아졌습니다. 고정된 calibration beta가 모든 OOD에서 90% 이상의 첫 전송 ACK를 보장하는 것은 아닙니다.

K60의 deadline miss는 약 49%이지만 overflow는 약 0.015%입니다. 이 조건의 주된 실패는 deadline 만료이며 대량 buffer overflow가 아닙니다. PPO의 K60 overflow는 SUS+CQI보다 0.000493~0.000922%p 높았습니다. 차이는 작지만 “모든 지표를 개선했다”라고 쓰면 안 됩니다.

K8→K48→K60은 사용자 수와 총 제공 부하가 함께 증가합니다. 16번에서 관측한 offered packet/slot은 약 2.550→15.309→19.128입니다. 이를 순수한 사용자 수 확장성 또는 시스템 용량 상한 측정이라고 부를 수 없습니다. V60max도 학습 범위 U(5,40)와 겹치는 U(5,60)이므로 속도가 전부 학습 범위 밖인 실험은 아닙니다.

## 논문에 반영할 판단

1. 주 결과는 **고정된 CQI4 정책이 여러 환경 변화에서도 비교한 기존 스케줄러보다 완료 패킷 goodput과 deadline miss를 개선한다**는 주장으로 잡는 것이 가장 강합니다.
2. 16번을 현재 기준으로 유지하되, deadline 관리와 고부하 결과에는 21번을 함께 제시하십시오. 하나의 최고 모델을 환경마다 교체한 결과를 단일 모델의 성능으로 제시하지 않아야 합니다.
3. 22번은 실패 사례가 아닙니다. NARROW에서도 잘 일반화하며 넓은 학습의 이득이 주로 고부하에 나타나는 결과로 정리하는 편이 정확합니다.
4. 다음 검증의 우선순위는 모델 간 작은 차이를 다른 training seed에서 재현하는 것입니다. 현재의 단일 seed 결과만으로 LR 재시작이나 넓은 학습 분포의 평균적 우위를 확정할 수 없습니다. 이 분석에서는 새 학습이나 평가를 시작하지 않았습니다.

## 검증과 해석 범위

- 원자료 9,000행의 world/episode/scheduler 조합이 중복·누락 없이 일치했습니다. 저장된 1,890개 paired 지표를 원자료로 재계산했고 최대 차이는 5.6e-08였습니다.
- 에피소드 내 paired 비교는 초기 topology·속도·부하를 맞춥니다. Queue admission에 따라 이후 traffic/CSI 난수 소비가 달라질 수 있으므로 모든 정책에 완전히 동일한 패킷 trace를 제공했다고 주장하지 않습니다.
- 완료 패킷 지연은 완료된 패킷만의 조건부 지표입니다. Jain 지표는 ACK 비트의 active-UE 간 공정성입니다.
- 비교 범위는 승인된 기존 6개 baseline입니다. SumRate-Greedy-SDS·SUS-RPS 등은 이번 sweep에 포함하지 않았으므로 그 방법들에 대한 우위를 의미하지 않습니다.
- 원자료·점추정·pointwise CI는 서버의 combined 결과이며, Holm 분석은 분석 단계에서 추가한 사후 민감도 검증입니다.
