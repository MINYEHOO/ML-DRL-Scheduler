작성 2026-08-06. **메인 정책 = QueuePostRZF_S40HL_CQI4 best.pt@409** (4-bit NR CQI
세계, held-out +13.9% 20/20). 이 폴더는 OOD·zero-shot 계열의 모든 스크립트

## 1. 프로토콜 불변 조건 (전 프로브 공통)

- **정책 완전 동결**: 재학습·미세조정 없음. β_m도 학습 세계 보정값 유지
  (zero-shot 전제 — OOD 세계에서는 의도적으로 미스매치 상태).
- **baseline은 세계마다 재튜닝**: 각 시나리오에서 SUS+CQI threshold를
  {0.60–0.80} 스윕해 최강값 채택 + SU+CQI anchor. 즉 비교는
  "제자리 재튜닝된 최강 휴리스틱 vs 동결 정책" — **마진은 보수적 하한**.
  (튜닝은 baseline에만 적용되는 자유도 — 정책은 평가-시 선택 파라미터 없음.)
- 시드 대역: **40000대 = pilot(threshold 선택·챔피언 검증) / 30000대 =
  test(n=40 평가)** — §2는 이 분리를 따름. 구판 8-seed 프로브(§4)는
  30000–30007에서 선택·평가를 겸했으므로 그 한계를 명시하고 인용할 것.
  **최종 논문 숫자용 20000+는 미접촉 예약**.
- 판정 규칙: n=8은 "한 자릿수 마진 = 지지 않음"(K48 규칙); n=40은 paired
  Student-t 95% CI로 "CI>0 확정 / tie" 판정.
- 에피소드 조건(활성 인원 등)은 시드가 결정 → 시나리오 간 paired 비교 성립.
  참고: 30002(활성 32명)·30006(28명)이 최대 포화 시드.

## 2. ⭐논문 그리드 (n=100, seeds 30000–30099) — 확정 결과

**2026-08-06 감사 수정 반영판** (외부 리뷰 3건 처리):
- **pilot/test 분리**: SUS threshold 선택을 미사용 시드 **40000–40007**로 이전
  → 30000–30039는 완전 독립 test set. (구판은 30000–30007이 튜닝·평가 양쪽에
  포함 = baseline에 유리한 누출이었음 → 우리 마진의 과소평가 방향)
- **챔피언 검증**: pilot에서 **12-baseline 전수** 평가 + SUS+MW 전용 threshold
  스윕까지 실시 → 6/6 세계에서 챔피언 정체 불변(SUS+CQI, P010만 SU+CQI).
  MW는 자기 최적 threshold에서도 격차 +212~+284로 열세. D26에서
  deadline-aware(EDF/DPF)는 2위조차 못 함.
- **D26 strict**: 원판은 deadline_max 12→6 변경이 정책 관측 정규화까지 바꿔
  엄밀한 zero-shot이 아니었음. 재실행판은 **env=U[2,6] / 정규화=/12(학습값
  동결)** 분리. 표의 D26 행은 strict 결과.

설계: 축당 1개, 분포-연장 방식(V는 상한 연장), STORM2 = 단일-축 정의 3개를

4. **층화(n_active 3분위)**: 확정-승 시나리오 전부 최고부하 3분위도 양수.
5. P010에서 최강 baseline이 SU+CQI로 교체 — 저부하→SU 최강 regime-map 일치.

**논문 표시 baseline 세트(2026-08-06 확정)**: 본문은 **6개 = {SUS, SU} ×
{CQI, PF, Random}**. DPF/MW/EDF는 부록 전체표·각주로만(위 챔피언 검증이
"wider 12-grid에서도 챔피언 불변"의 근거).

## 3. ⭐인원 축 zero-shot (고정 인원, n=100) — 확정 결과

**설계 (2026-08-06 사용자 재설계)**: 학습 세계를 그대로 두고 **유저 수만
고정 변경**. 학습 시 경험 범위는 활성 16–32명 → K=8은 아래로, 48/60은
위로 벗어남. 나머지 전부 학습값(nr4bit, 속도 U(5,40), p_a~U(0.15,0.50),
p_csi 0.6, 마감 U[3,12], β_m은 K=32 보정 동결). 프로토콜은 §2와 동일
(40k pilot에서 T* 선택 → 30000–30039 n=40 평가, 표시 baseline 6종,
paired CI). 스크립트 `scripts/ood_userscale_cqi4.py`, 데이터
`results/ood_userscale_k{8,48,60}.csv`.

| K (활성) | T* | PPO | SUS+CQI | SUS+PF | SUS+Rnd | SU+CQI | SU+PF | SU+Rnd | 챔피언 | paired ±CI | 판정 | 승수 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| **8** | 0.80 | **3438** | 3253 | 3213 | 3146 | 3314 | 3230 | 2914 | SU+CQI | **+124±27** | **CI>0** | 95/100 |
| **48** | 0.75 | **1443** | 1079 | −12044 | −11238 | −8027 | −15677 | −19031 | SUS+CQI | **+364±56** | **CI>0** | 92/100 |
| **60** | 0.80 | **−2121** | −2307 | −19787 | −18627 | −14954 | −23538 | −26919 | SUS+CQI | **+185±76** | **CI>0 ← n=40 tie에서 승격** | 73/100 |

2026-08-10 확장(+60시드, `ood_userscale_ext100_*.csv`): **K60이 tie
(+144±148, n=40) → CI>0 확정(+185±76, n=100)으로 승격** — 포화 지대에서도
통계적으로 유의한 우위. K8/K48 판정 유지, 마진 정밀화.

핵심 판독:
1. **인원 축 양방향 확정 승 + 극단에서 동급**: 학습 범위 절반(K8)과 1.5배
   (K48)에서 CI>0 확정, ~1.9배(K60)에서 통계적 동급. 붕괴 지점 없음.
2. **depth 자가 적응이 인원에 단조**: 1.91 (K8) → 3.40 (K48) → 3.71 (K60).
   재학습 없이 인구가 늘수록 스스로 깊게 다중화 — 파라미터 K-독립 구조의
   기능적 증거(정책 가중치는 세 세계에서 동일 파일).
3. **챔피언 교체가 여기서도 재현**: K8에서만 SU+CQI, K48/60은 SUS+CQI —
   §2의 P010(저부하→SU) 패턴과 동일한 regime map.
4. **rate-blind 계열의 붕괴가 인원 축에서 가장 극적**: K48 이상에서 PF/
   Random은 −10,000 이하. K8에서는 6개가 2906~3311로 압축(결정 여지 소멸).
5. **K60은 P065류 포화**: PPO를 포함해 전원 음수. tie는 "인구 외삽 실패"가
   아니라 "용량을 2~3배 초과하면 누구도 잘할 수 없다"의 재확인.

**주의 (논문 명시 필수)**: (a) UE당 도착률이 고정이라 **인원과 부하가 함께
움직임** — 명목 ρ ≈ 0.4 (K8) / 2.4 (K48) / 3.0 (K60). 순수 인구 축이
아니라 "사용자 증가 = 수요 증가" 시나리오. (b) 같은 시드라도 K가 다르면
토폴로지가 달라 **K 간 행은 paired가 아님** (각 K 내 PPO vs baseline만 paired).

*(구판: 비율 방식 K=16/24/32/48, n=8, pilot/test 겸용, baseline 2종 —
`results/scaling_zeroshot_cqi4.csv`. 프로토콜 불일치로 대체됨. 참고값
K16 +7.1 / K24 +13.4 / K32 +11.4 / K48 +20.8%. continuous판 Ent02는
`results/scaling_zeroshot.csv`.)*
